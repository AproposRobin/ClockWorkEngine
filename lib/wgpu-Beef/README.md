# wgpu-Beef

[Beef](https://www.beeflang.org/) bindings for [wgpu-native](https://github.com/gfx-rs/wgpu-native) **v29.0.0.0**, with a triangle sample (`wgpu-Beef-Test`) that builds for both native (Win64) and browser (wasm32/WebGPU) from one source.

See [SETUP.md](SETUP.md) for build & run instructions (including Emscripten setup for the web sample).
